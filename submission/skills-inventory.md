# Skills inventory

| Skill | Activate when | Principal output |
| --- | --- | --- |
| `omarchy-plugin-design` | Planning or choosing an Omarchy surface | Design contract and kind decision |
| `omarchy-plugin-scaffold` | Starting a plugin repository | Runnable six-kind-aware scaffold |
| `omarchy-qml-patterns` | Implementing or reviewing hosted QML | Host-correct QML changes |
| `omarchy-bar-widget` | Building a bar widget or its settings/panel | Responsive bar surface |
| `omarchy-panel-overlay` | Building a panel, overlay, or menu | Correct window and lifecycle behavior |
| `omarchy-service-ipc` | Adding shared state, processes, or IPC | Stable service and IPC contract |
| `omarchy-plugin-debug` | Diagnosing discovery, loading, or runtime behavior | Evidence-backed diagnosis |
| `omarchy-plugin-test` | Validating a plugin or regression | Layered test report |
| `omarchy-plugin-demo` | Preparing a safe demo or screenshot | Reversible fixture-driven demo |
| `omarchy-plugin-release` | Preparing a versioned release | Release preflight report |
| `omarchy-plugin-publish` | Preparing an Omarchy marketplace issue | Exact issue body, held for owner approval |
| `omarchy-plugin-migrate` | Moving an older installer integration to Omarchy 4 | Split shell/machine migration plan |

All skills are local instruction bundles. The plugin declares no MCP server and
no ChatGPT app connector.
