## Short description

Build, test, debug, and publish Omarchy plugins.

## Long description

Build production-ready Omarchy 4 Quattro shell plugins with a focused set of
engineering skills. Choose the correct shell surface, generate a working
repository, implement native QML patterns, validate manifests and security
boundaries, debug load and runtime failures, create deterministic demos,
prepare releases, migrate older integrations, and assemble an exact community
marketplace submission.
