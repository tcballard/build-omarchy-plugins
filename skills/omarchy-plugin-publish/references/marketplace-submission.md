# Omarchy community marketplace submission

Verified against
[`HANCORE-linux/omarchy-plugin-marketplace`](https://github.com/HANCORE-linux/omarchy-plugin-marketplace)
on 29 August 2026.

## Repository contract

- public GitHub repository root URL;
- one plugin with root `manifest.json`;
- root README with installation and removal instructions;
- root license and documented external dependencies;
- globally unique permanent plugin ID outside `omarchy.*`; and
- optional single root preview named `preview.png`, `.jpg`, `.jpeg`, `.webp`,
  or `.avif` (currently at most 50 MB and 40 megapixels).

## Listing values

Categories are case-sensitive:

`Appearance`, `Desktop`, `Developer Tools`, `Hardware`, `Productivity`,
`System`, `Widgets`, `Other`.

Choose one to three tags:

`ai`, `bar`, `games`, `hyprland`, `launcher`, `media`, `power-management`,
`quickshell`, `security`, `system`, `workspaces`.

## Exact issue

The title is `[Plugin]: <human-readable plugin name>`. Preserve the six body
headings and five checklist statements generated by `prepare_submission.py`.
Show both to the owner and obtain explicit approval before running:

```bash
gh issue create \
  --repo HANCORE-linux/omarchy-plugin-marketplace \
  --title "[Plugin]: Plugin Name" \
  --body-file /path/to/approved-body.md
```

## After opening

Automated compatibility validation and a static exact-commit security baseline
comment on the issue. Fix the repository or edit the existing issue to retry;
do not open duplicates. New publication requires a current matching report and
an authorized maintainer's `approved-and-verified` label event.

The scan reports `passed`, `review-required`, or `needs-fixes`. It is not a
security audit. Installation still clones mutable current upstream HEAD, so a
later commit is outside the verified snapshot until a full-SHA update request is
approved.

Use the marketplace's unified verification form for an existing snapshot,
standard-installation approval, or a newer full commit.
