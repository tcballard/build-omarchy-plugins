# Privacy policy

Effective: 29 August 2026

Build Omarchy Plugins is a skills-only developer tool. It does not operate a
server, create accounts, collect analytics, sell data, or transmit project files
to the developer.

The plugin's instructions and scripts operate on files and commands available in
the user's ChatGPT or Codex execution environment. If a user asks ChatGPT or
Codex to browse documentation, access GitHub, or publish an issue, those actions
are handled by the services the user has chosen to use and are governed by those
services' policies.

Generated Omarchy plugins may have their own dependencies and data behavior.
Their authors are responsible for documenting that behavior; this policy does
not cover third-party plugins generated with the toolkit.

Questions may be raised through the repository's public support channel without
including private source code, credentials, or personal data.
